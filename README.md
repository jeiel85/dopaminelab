## 🌟 주요 기능 (Features)

1. **🍀 럭키비키 억까 변환기 & 인스타 짤 카드 스튜디오**
   - 일상의 모든 억까를 4대 페르소나로 재해석:
     - 💖 **원영적 사고 (완전 럭키비키잔앙)**: 초긍정 행운의 빌드업
     - 🧊 **극T 팩폭 보고서**: 손익 계산 및 팩트 기반 솔루션
     - 🧘 **극락왕생 해탈적 사고**: 삼라만상 무소유 드립
     - 🚀 **도파민 숏폼 알고리즘 뇌**: 릴스/쇼츠 100만뷰 떡상 드립
   - 9:16 인스타 스토리 및 1:1 정방형 짤 카드 PNG 다운로드 & 클립보드 복사

2. **🧠 전국민 숏폼 도파민 뇌 상태 진단소**
   - 8가지 현실 공감 문진표로 측정하는 숏폼 중독도 & 브레인롯(Brainrot) 지수
   - 5각 레이더 차트 분석 + 맞춤형 뇌 힐링 처방전 발급 및 공유

3. **🎮 도파민 서바이버 : 알고리즘 탈출기 (미니게임)**
   - 억까(월요일 알람 ⏰, 배터리 1% 🪫, 잔소리 🗣️, 읽씹 💀)를 피하고 도파민 캔디(🍬)와 럭키 클로버(🍀)를 수집하는 아케이드 게임
   - 무적 실드, 도파민 피버 모드, 콤보 시스템, 하이스코어 저장

4. **🔊 2026 바이럴 밈 사운드보드**
   - Web Audio API 기반 실시간 사운드 합성 (샤방 팡파레, 팩폭 부저, 목탁 소리, 도파민 빔, 버블 팝 등)

## 🚀 빠른 시작 (Getting Started)

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 배포용 빌드
npm run build
```

브라우저에서 `http://localhost:3000`으로 접속하여 실행할 수 있습니다.
